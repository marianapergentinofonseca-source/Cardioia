# CardioIA

Projeto base da disciplina **Tecnologia em Inteligência Artificial** (turma **2TIAPR**, 2026).

Assistente de apoio à análise de exames cardiológicos, construído em **React 19 + Vite 8**.

Cada aluno versiona o próprio repositório:

```text
https://github.com/SEUUSUARIO/cardio-ia-TIAPR2026.git
```

Troque **SEUUSUARIO** pelo seu usuário do GitHub.

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173/`.

O passo a passo completo da criação deste projeto está em [`AULA-19-08-2026-projeto-base-cardioia.md`](./AULA-19-08-2026-projeto-base-cardioia.md).
